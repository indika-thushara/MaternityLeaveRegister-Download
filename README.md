# Maternity Leave Register System

**A Windows Desktop Application for Maternity Leave Management**

The Maternity Leave Register System is a desktop application developed to assist administrative officers in managing maternity leave records in Sri Lankan government institutions.

The application provides maternity leave date calculations, government holiday management, leave record management, and database backup and restoration functionality.

## Main Features

- **Maternity Leave Calculation**
  - Calculate maternity leave dates.
  - Calculate the first 84-day paid leave period.
  - Exclude Saturdays, Sundays, and registered government holidays from the paid leave calculation.
  - Preview calculated dates before saving.

- **Government Holiday Management**
  - Add and manage government holidays.
  - Edit holiday dates and types.
  - Prevent duplicate holiday entries.

- **Leave Records Management**
  - Add and update maternity leave records.
  - Search records by salary number or employee name.
  - View maternity leave information in an organized table.

- **Database Management**
  - SQLite database integration.
  - Database backup functionality.
  - Database restoration support.

## System Requirements

- Windows 10 or Windows 11 (64-bit).
- Sufficient disk space for installation and database storage.
- Write permission for the application database and backup folders.

Refer to the release notes for version-specific installation requirements.

## Installation

2. Download the latest `MaternityLeaveRegister-Setup.exe` file.
3. Run the installer.
4. Follow the installation instructions.
5. Launch the application.

## Important Information

- This application is intended for use in Sri Lankan government institutions.
- The application uses an SQLite database.
- Users should regularly back up their database.
- Protect employee information and database backup files.
- This public repository distributes the compiled application installer only. The application source code is maintained separately in a private repository.
